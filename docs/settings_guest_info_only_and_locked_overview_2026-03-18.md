# Settings-Info für Gast und gesperrte Zentrale

- Gäste dürfen `/settings` öffnen, aber nur den Tab `Info`.
- Gesperrte Settings-Tabs bleiben sichtbar und zeigen ein Schloss.
- Klick auf gesperrte Tabs zeigt eine interne Kein-Zugriff-Ansicht in der Settings-Seite.
- Zentrale bleibt für Gäste in Bottom-Navigation und Menü sichtbar, aber mit Schloss.
- Zugriff auf `/overview` löst für unberechtigte Benutzer die 403-Seite im normalen Layout aus.
