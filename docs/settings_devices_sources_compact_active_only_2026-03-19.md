# Settings Devices Sources Compact Active-Only Patch

- Reihenfolge im Geräte-Tab auf Instanzen -> Neue Instanz -> Sources umgestellt.
- Source-Templates als kompaktes 2-Spalten-Grid reduziert.
- Source-Karten zeigen nur noch Namen und optional den Aktiv-Status.
- Auswahl für neue Instanzen auf aktive Sources begrenzt.
- Seed- und Migrationsstand so angepasst, dass vorerst nur DWARF3 aktiv ist.
