# Session-Detail auf Session-Ebene getrennt von RAW-Einzelbildern

- Session-Seite zeigt nur Session-Zusammenfassung und Session-Bild
- RAW-Einzelbilder wurden auf eigene Unterseite `/sessions/<id>/raw` verlegt
- Session-Bild priorisiert PNG-Vorschau, FITS bleibt als Dummy-Modul vorbereitet
- AstroManager-Vergleich bleibt als separates Modul vorbereitet
