# Finales HUD-UI-Rebuild

## Ziel
Die Weboberfläche von einer responsiven Webseitenoptik zu einer kompakteren, appigeren HUD-/Observatory-Konsole umbauen.

## Umgesetzt
- Fixierter Space-/HUD-Hintergrund.
- Kompakte App-Bar mit Logo, `DeepSky Sessions`, Version und Settings-Zugang.
- Galerie als dichte Session-Rows statt großer Website-Karten.
- Monatsgruppen als kompakte App-Sektionen.
- Target-Detail-Sessions im gleichen Row-Muster wie Galerie.
- Session-Detail als kompaktes Instrumentenpanel.
- Programm-Info als kompakte Collapse-Module.
- Globale Versionsanzeige aus derselben Program-Info-Quelle wie die Programm-Info.
- Galerie/Session-Detail weiterhin nur echte Light-Sessions.
- Sun/Moon zeigen bei fehlendem Zielnamen `Solarsystem`.
