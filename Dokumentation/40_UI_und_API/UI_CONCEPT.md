# AstroManager UI-Konzept

## Ziel

Die UI soll fachlich sinnvoll und gleichzeitig technisch nachvollziehbar bleiben.

## Tabs

### Übersicht
Allgemeiner Status, letzte Runs, Pipeline-Informationen.

### Targets
Logisch aufbereitete Zielansicht.

### DB
Rohdaten- und Tabellensicht für Kontrolle und Debugging.

## Targets-Tab

### Deep-Sky-Targets
Zielkarten mit:
- NASA-Bild
- finalem Namen
- Typ
- Sternbild
- RA/DEC
- Distanz
- Status
- Quellenbezug

### Systemziele
Getrennte Darstellung für Sun und Moon.

## Spätere Ausbaustufen

- Suche
- Filter
- Ziel-Detailseite
- Sessions pro Ziel
- Stack-Hierarchie
- Qualitätsansicht
- technische Detailsicht
